PositionTag uint8 flags, successive bits starting at bit0:
WhiteCanCastleKingSide, WhiteCanCastleQueenSide, BlackCanCastleKingSide,
BlackCanCastleQueenSide, InCheck, BlackToMove, WhiteToMove, enPassantHash.
CASTLING_FLAG combines the four castling flags.
Status uint8: Checkmate=0, Draw=1, Unknown=2.
type Position struct {
 Board Bitboard
 EnPassant Square
 Tag PositionTag
 hash uint64
 Positions map[uint64]int
 positionsMutex sync.RWMutex
 HalfMoveClock uint8
}
SetTag/ClearTag/ToggleTag(PositionTag); HasTag(PositionTag) bool uses any-bit
intersection. HasCastling() bool tests any castling flag. Turn() Color is White
when WhiteToMove is set, Black otherwise; ToggleTurn flips both turn flags.
IsEndGame() bool delegates to Board for Turn. IsInCheck() bool reads InCheck.

Hash() uint64 lazily initializes when hash is zero: ensure legal-EP metadata
then generateZobristHash and cache it. Existing independent hash helpers own the
key stream and EP eligibility implementation; retain their interface semantics.
findEnPassantCaptureSquare(Move) Square returns destination XOR 8.

MakeNullMove() Square: ensureEnPassantHash before saving raw EP target; set EP
to NoSquare, increment half-clock with uint8 arithmetic, toggle turn and update
the null key using the provided helper. Leave EP eligibility flag available for
undo and don't touch board/check/map. Return old target.
UnMakeNullMove(Square): reverse the null-key delta with the post-null turn first,
then restore target, decrement half-clock, toggle turn. Restore cold/warm hash
and eligibility behavior as required by the helper; don't recompute check/map.

partialMakeMove(Move) / partialUnMakeMove(Move): only board and turn change.
Apply/undo the move, captures (EP victim is behind destination), promotions to
the mover's color, and castling rook movement. Board.Move handles forward rook
movement when king coordinates identify castling; undo must explicitly return
the rook. Don't modify check/EP/hash/half-clock/repetition metadata. Partial
undo flips turn first to recover the original mover's promotion color.

(oldEnPassant Square,oldTag PositionTag,oldClock uint8,legal bool).

true for supplied valid packed moves. The move generator validates legality.
