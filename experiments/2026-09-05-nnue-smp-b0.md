## CPU affinity

WSL exposes 16 logical CPUs, 8 physical cores, SMT pairs `(0,1)` through `(14,15)`, and `Cpus_allowed_list: 0-15`. Pinned fastchess assigns one CPU to each concurrent game thread; the two alternating engines in one game share that CPU, which is appropriate for one-thread engines because only one searches at a time.

The corrected two-concurrency smoke requested CPUs `0,2`; both engine roles reported CPU 0 in one game thread and CPU 2 in the other. Its manifest is `output/nnue-smp-b0-20260905/affinity-smoke-attempt2/manifest.json`, SHA-256 `7f5a8c01b657eeacb75d67bd5d223fcc8f898c7318c0f4df2971da1292120f2d`. The held c8 match selects `0,2,4,6,8,10,12,14`, one sibling from every physical core. If the cpuset, topology, or affinity preflight differs, the launcher fails before creating a run; the fallback requires a separately reviewed c1 manifest on one CPU.
