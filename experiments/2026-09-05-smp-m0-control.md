# SMP M0 control ownership — 2026-09-05

Sol implemented the first bounded ownership change in ngn-worker-state. Root reviewed, integrated and verified the exact source in ngn-next. This changes stop/node ownership and same-instance search serialization; it does not introduce helper workers or make different engine instances safe for concurrent search.

Each SearchEngine has its own atomic stop/configured-node control and session mutex. SearchInfo carries an explicit control pointer. Legacy package entry points route through the default instance; each UCI receiver uses its own instance. UCI's prepared entry preserves a stop arriving between goroutine launch and session entry. Same-instance searches remain serialized through their final callbacks.

The behavior gate records production iterative deepening in fresh fixture processes, with a second warm search in each. Its 11 fixtures include EP, castling, promotion, terminal roots, stop/node boundaries, repetition, and two complete historical game prefixes. It records predecessor state and a digest of the whole board, as well as move/score/nodes/PV and all uint64 diagnostics at completed-depth callbacks and return. Metadata differences are reported separately. Fixed node behavior, including the legacy 256 cold/257 warm witness, is intentionally preserved.
