Implement a chess-board container from scratch in package engine. Write
bitboard.go, independent tests, and RESULT.md. Do not inspect any implementation
outside this directory, use a network, fetch data, or modify the supplied helper
files. The controller will compare hidden pre-existing oracles after completion.
Use Go standard library only, ordinary safe Go, no assembly or unsafe.

The supplied piece/square/move helpers were independently generated. The
contract_values.go file is only a synthetic table adapter, not production values.

Required representation (other package files access these fields):
type Bitboard struct {
  pieces [13]uint64
  whitePieces, blackPieces uint64
  accMG, accEG, accPhase int
  mailbox [64]Piece
}
Zero value is an empty board. Square A1=0 through H8=63. A square mask is 1<<sq.
Piece values are NoPiece=0, WhitePawn..WhiteKing=1..6,
BlackPawn..BlackKing=7..12. Valid board occupants are disjoint. Caller-provided
piece/square arguments use these ranges unless NoSquare is explicitly specified.
Maintain occupancy, mailbox, and additive evaluation sums through mutations.
External arrays mgPST, egPST [13][64]int and piecePhaseInc [13]int supply each
piece-square's contributions. NoPiece contributes zero. These arrays may change;
recomputeAccumulator rescans the occupancy using their current values.

Required functions and behavior:
(*Bitboard).Pawns/Knights/Bishops/Rooks/Queens/Kings() uint64: both colors' masks
of that type. GetWhitePieces/GetBlackPieces() uint64: each side's occupancy.
GetBitboardOf(Piece) uint64 returns that indexed mask (including empty slot 0).
AllPieces() map[Square]Piece returns an independent map of occupied squares.
PieceAt(Square) Piece returns mailbox value; NoSquare returns NoPiece.

Clear(Square,Piece): NoPiece is a no-op. Otherwise remove that piece's square bit
and that side's occupancy bit, and subtract the specified contribution. Clear
mailbox only when it currently equals the specified piece. This last rule matters
when a capture temporarily has a newly placed mover and the captured occupant
overlapping in separate masks. Contribution removal is driven by the piece
argument even if mailbox already records the mover. Calls are balanced by the
engine; do not infer a different piece from the mailbox.

UpdateSquare(square,newPiece,oldPiece): remove the old contribution/occupancy
according to Clear, add the new contribution and occupancy if nonempty, and
record newPiece as mailbox occupant. It supports promotion/capture replacement.

Move(src,dest,sourcePiece,destinationPiece): if either square is NoSquare, leave
the board untouched. Remove the specified destination and source pieces, then
place sourcePiece at dest (or leave dest empty when NoPiece). A king moving
E1->G1/E1->C1 also moves its white rook H1->F1/A1->D1; similarly black king
E8->G8/E8->C8 moves black rook H8->F8/A8->D8. Castling recognition is this board
update rule, not a legality test; legality is the caller's job. Moving a king
backwards does not automatically undo the rook; the position layer handles it.

StartingBoard() Bitboard: ordinary 32-piece chess initial arrangement, consistent
accumulators and all occupancy views. No external setup dependency.
(*Bitboard).copy() Bitboard: independent value copy, no aliasing.
(*Bitboard).recomputeAccumulator(): rebuild accMG/accEG/accPhase from occupancy.
(*Bitboard).IsEndGame(Color) bool: true for White/Black when that side has no
knight, bishop, rook or queen; false for NoColor. Pawns/kings don't disqualify.
(*Bitboard).Draw() string: debugging representation starts with a newline then
" A B C D E F G H\n". Rows 8 down to 1 start immediately with the numeric rank,
then A..H entries, each followed by a space, then newline. Empty is "-".
White pawn/knight/bishop/rook/queen/king glyphs: ♙ ♘ ♗ ♖ ♕ ♔.
Black corresponding glyphs: ♟ ♞ ♝ ♜ ♛ ♚.

SquareMask [64]uint64, initialized by initSquareMask() [64]uint64.
bitScanForward(uint64) uint8: least significant set bit, or 64 for zero.
bitScanReverse(uint64) uint8: highest set bit, or 127 for zero (legacy contract).
PopCount(uint64) int: number of set bits.
