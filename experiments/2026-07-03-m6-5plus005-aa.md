## Predeclared PASS rule (M6 — 5+0.05 enable gate)

PASS **requires ALL four**:
- **(a) No bias:** Elo ≈ 0 — SPRT H0-accepts OR reaches the game cap with the 95% CI comfortably
  straddling 0 (same A/A terminal shape as M5). A decisive H1 in EITHER direction = FAIL.
- **(b) Clean clocks — THE headline criterion:** flag-outs new 0 / base 0. **ANY flag-out (either side) =
  FAIL for the 5+0.05 option.** This is the whole question — a halved clock at c8 is where NGN's time
  manager would first crack; a single flag-out means 5+0.05 is not safe as a filter TC (fall back to
  10+0.1 or drop to a lower concurrency).
- **(c) Adjudication fires:** the "Adjudicated early: N decisive, M draw" line with N > 0 AND M > 0 (both
  kinds) — confirms adjudication behaves at the faster TC.
- **(d) Throughput:** games/hr measured and reported; expected ≈ 2× the 10+0.1 baseline (~1900/hr). This
  is the payoff being validated for Stage-1 filters / SPSA.

On PASS: 5+0.05 c8 is cleared as an OPTION for Stage-1 filters and SPSA batches (NOT for per-change
verdicts — those stay 10+0.1 until 5+0.05 shows sign-agreement on 2-3 changes). On FAIL (esp. any
flag-out): 5+0.05 c8 is rejected for the mill; filters/SPSA stay at 10+0.1 c8 (or retry 5+0.05 at lower
concurrency in a follow-up).
